where it lives

A block between the sent message and the answer: four stations linked by 1px wires. The current action sits on the line below, next to the clock and stop.

what changes

The current station uses accent and breathes; completed ones turn success; future ones stay dim. On completion the track becomes a one-line receipt in history — no permanent card.

multi-session

Every running session shows the same track in miniature in the sidebar (4 segments) and the phase as text. The tab gets a dot; the statusbar sums the sessions.
