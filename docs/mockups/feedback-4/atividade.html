where it lives

A fixed strip above the composer with the latest event. Expanded, it shows the turn log: tool, target, duration, and state. Collapsed, only the 30px line remains.

what changes

The chat stays clean; proof of work becomes an event log, not message decoration. Completed events turn green, the current one blinks, and the log cuts at 8 rows with “+N” at the end.

multi-session

Running sessions leave recent and move up to working, with the last event and progress. When they finish, they return to recent with an unread dot.
