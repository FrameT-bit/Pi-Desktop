# Provider logo sources

Generated by `tools/gen-logos.sh` into `resources/logos/<slug>-{dark,light}.png`.
The script uses a fixed 2px block; `tools/pixelify.py` handles the grid and
tint. Line marks use `--nearest`; filled marks use averaged sampling.

## Simple Icons (CC0-1.0)

Source: <https://simpleicons.org> — see `simple-icons-LICENSE`.

- `anthropic.svg`, `googlegemini.svg`, `mistralai.svg`, `nvidia.svg`,
  `ollama.svg`, `meta.svg`, `deepseek.svg`
- `openai.svg` (v11; the glyph left the `develop` tree)
- `opencode.svg`, `vercel.svg`, `moonshotai.svg`, `minimax.svg`
- `huggingface.svg`, `githubcopilot.svg`, `xiaomi.svg`, `openai.svg`

Some full-bleed Simple Icons marks do not survive at 24px when tinted, so their
alpha is eroded before pixelation:

- `huggingface-mask.png` — face/hands silhouette with the eyes and mouth open
- `minimax-mask.png` — waveform with its gaps preserved
- `openai-mask.png` — the interlocking knot
- `xiaomi-mask.png` — the square with the `mi` cut-outs

The masks are derived from the matching SVG with a 21px minimum filter; the
original SVG is kept next to each mask for provenance.

## Custom marks

No usable monochrome asset was available for these, so they are simplified
glyphs in the project's pixel language:

- `openrouter.svg` — two opposing arrows
- `antling.svg` — block `L` monogram for Ant Ling
